# Placeholder asset provenance

All models, PNG textures and WAV files in this directory were generated locally
for this prototype by `AGT_TEMPLATE/tools/generate_placeholders.py` during an
AI-assisted coding session on 14 November 2026. They were not downloaded from
an asset marketplace. Retain the script and disclose the assistance as required
by the coursework brief. No third-party asset licence is claimed for these
original generated outputs.

- `models/chair.obj`, `lamp.obj`, `planter.obj`: distinct arrangements of cuboids,
  exported as triangulated OBJ with normals, UVs and MTL diffuse texture paths.
- `textures/`: small procedural RGB PNGs; sign lettering uses hand-specified 5x7
  bitmap patterns. The six sky images are identical solid colours.
- `audio/`: original synthesised sine-wave cues and a quiet four-note background
  loop, exported as mono PCM16 WAV at 22050 Hz.

The font, engine and bundled libraries outside this directory retain their
existing notices and licences. FMOD is supplied by the university template.
