# IN3026/INM710 Advanced Games Technology

The C++/OpenGL games engine for the Advanced Games Technology labs and
coursework.

**What this download is:** see [LESSON.md](LESSON.md).
**How to build it, and how the engine fits together:** see
[CLAUDE.md](CLAUDE.md). It is written for AI coding assistants, which read it
automatically, but it is ordinary documentation and worth reading yourself.

## Quick start

1. Extract the whole ZIP. Do not open the solution from inside the ZIP.
2. Open `engine.sln` in Visual Studio 2026.
3. Press F5.
